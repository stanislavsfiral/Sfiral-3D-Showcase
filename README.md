# Sfiral 3D Showcase

Демонстрационная 3D-витрина проекта **Sfiral Chirality Auditor**.

## Что показывает

- 3D-структуры из `models.json`;
- оригинал;
- зеркальное представление;
- overlay оригинала и зеркала;
- базовый геометрический паспорт модели;
- локальную загрузку своей SDF/JSON-модели в браузере.

## Важно

Это **не полноценный лабораторный аудитор**.

Полноценная рабочая версия — **Sfiral Chirality Auditor v0.3.1-lab** — существует в отдельном Python/лабораторном контуре и предназначена для воспроизводимого геометрического аудита.

Данная витрина подходит для демонстрации, образовательных целей и быстрого визуального знакомства с методом.

## Технологии

- HTML
- JavaScript
- Three.js
- GitHub Pages

## Файлы

- `index.html` — страница витрины;
- `models.json` — набор демонстрационных структур;
- `reports.json` — опциональные полные отчёты, если они сгенерированы Python-ядром.
